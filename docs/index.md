# APGAP Developer Documentation

Welcome to the APGAP Developer Documentation. This portal is the central hub for developers looking to contribute to the development of APGAP. This documentation is a living document. If you find that something is missing, please create an issue in the [documentation GitHub repository](https://github.com/azpathogens/apgap-dev-documentation), or consider opening a pull request.
